# Arabic RTL Rule for Antigravity

- Always format Arabic responses and textual explanations with Right-to-Left (RTL) reading flow and alignment in mind.
- When generating Markdown or rich text with mixed Arabic and English/code, ensure Arabic paragraphs and bullet points are cleanly aligned from right to left (RTL), preserving code blocks and technical identifiers in pristine LTR syntax without bidirectional character distortion.
- For user-facing markdown documentation or chat sections in Arabic that require strict visual alignment, wrap the Arabic section in `<div dir="rtl">...</div>` or ensure bidirectional punctuation marks are placed correctly at the ends of phrases.
